# نوبتهاب (NobatHub) - پلتفرم هوشمند نوبت‌دهی و مدیریت کسب‌وکار

سامانه جامع نوبت‌دهی آنلاین، مدیریت مراجعین، سیستم معرفی دوستان و پشتیبانی هوشمند طراحی‌شده برای سالن‌های زیبایی، کلینیک‌ها، مطب‌ها و مراکز خدماتی.

---

## 🌟 ویژگی‌های کلیدی

1. **تقویم و تاریخ‌های استاندارد شمسی (جلالی):**
   - تطابق کامل با تقویم رسمی ایران در تمام بخش‌ها، یادآوری‌ها و گزارش‌ها بدون خطای سال کبیسه.

2. **صفحه ثبت‌نام عمومی (`/register`) با امنیت بالا:**
   - مجهز به **کپچای ریاضی ضداسپم** جهت جلوگیری از ثبت‌نام‌های فیک و ربات‌ها.
   - پشتیبانی از سیستم ارجاع و لینک اختصاصی (`?ref=...`).
   - اعطای **۲ ماه اشتراک ۱۰۰٪ رایگان هدیه** به صورت خودکار به تمام ثبت‌نام‌های جدید.

3. **سیستم تایید تلگرامی مدیریت:**
   - دریافت اطلاعات کسب‌وکارهای جدید در ربات تلگرام ادمین با قابلیت تایید (`approve_reg_`) یا رد (`reject_reg_`) با یک کلیک.

4. **باشگاه معرفان و پاداش معرفی (Referral Program):**
   - اعطای **۳۰ روز اشتراک رایگان** به معرف به ازای هر پرداخت یا تمدید اشتراک توسط کسب‌وکار معرفیشده.
   - ارسال آنی پیامک و نوتیفیکیشن تبریک در تلگرام.

5. **داشبورد کسب‌وکار و اشتراک:**
   - کارت وضعیت اشتراک و زمان باقیمانده به روز و تاریخ انقضای شمسی.
   - لینک انحصاری معرفی با قابلیت کپی سریع و مشاهده آمار معرفی‌ها.
   - مدیریت لیست مراجعین و تغییر وضعیت (انجام شد، کنسل، در انتظار).

6. **دانلود گزارش اکسل فعالیت‌ها (CSV):**
   - دریافت آنی فایل اکسل مراجعین و فعالیت کسب‌وکارها از مسیر `/api/admin/reports/business-activity-csv`.

7. **پشتیبانی هوشمند هوش مصنوعی (Gemini Flash):**
   - چت‌بات پشتیبانی هوشمند آموزش‌دیده روی امکانات نوبتهاب به همراه دکمه هدایت مستقیم به آیدی تلگرام پشتیبان رسمی: `@NobatHubseller`.

## 🚀 نحوه نصب و راه‌اندازی محلی

```bash

npm install

npm run dev

# بیلد نهایی پروژه
npm run build
```
